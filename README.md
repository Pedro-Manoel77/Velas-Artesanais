#  A Mística — Velas Artesanais

Site catálogo para uma loja de velas artesanais.

##  Sobre o projeto

O projeto foi desenvolvido para apresentar produtos de uma loja de velas artesanais, permitindo que o usuário:

- Visualize os produtos disponíveis
- Escolha aromas e quantidades
- Adicione produtos ao carrinho
- Veja o valor total da compra
- Envie o pedido pelo WhatsApp

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
